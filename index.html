Book a Slot

Expo SDK 58 · Supabase · Edge Functions · Razorpay · Push · GitHub Actions

A booking app for small businesses. Customers book slots in the business's time zone and pay a deposit; owners see bookings arrive live.

  • Booking rules enforced in Postgres: an exclusion constraint makes double booking impossible, even under load.
  • Row-level security on every table, checked by 30 automated attack-style tests using only the public key.
  • Payments through a server-created checkout and an HMAC-verified, idempotent webhook, tested end to end.
  • Unpaid holds expire after 15 minutes; reminders run on a schedule; in-app account deletion.

RLS Check

TypeScript · Postgres · Supabase · Vite · CLI

A free tool that reviews a Supabase project's security and explains each problem in plain English, with the SQL to fix it. It runs in the browser and never sees your data.

  • Catches tables with RLS off, always-true write policies, policies that trust user_metadata, views that skip RLS and unsafe SECURITY DEFINER functions.
  • Command-line mode for CI: fail a pipeline when a migration opens a table by mistake.
  • Used on Book a Slot, where it found and fixed excess table privileges.
